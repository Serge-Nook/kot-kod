# Кот-код

Графический Git-клиент с русскоязычным интерфейсом для Linux и Steam Deck: аналог GitHub Desktop с поддержкой **GitHub** и **GitVerse**.

Автор: Горшков Сергей Владимирович · [nookbat.ru](https://nookbat.ru)

## Возможности

- Изменения: статус, единый и параллельный просмотр различий с подсветкой синтаксиса, индексация файлов, блоков и отдельных строк, отмена изменений с подтверждением.
- Коммиты: краткое описание и подробности, соавторы (`Co-authored-by`), amend, история сообщений, черновики сохраняются автоматически.
- Синхронизация: fetch, pull (merge/rebase), push, публикация ветки, обработка отклонённого push, `--force-with-lease`, автоматический fetch.
- История: граф коммитов, поиск по сообщению, автору и хешу, cherry-pick, revert, reset (soft/mixed/hard), checkout коммита.
- Ветки: создание, переключение (со stash или переносом изменений), переименование, удаление локально и на сервере, merge / `--no-ff` / squash, rebase, интерактивный rebase (pick/reword/squash/fixup/drop, перестановка).
- Конфликты: просмотр нашей и их версии, выбор одной из них или ручная правка результата, продолжение/пропуск/отмена операции.
- Stash, теги (лёгкие и аннотированные), remote, `.gitignore` с шаблонами, автор коммитов на уровне репозитория.
- Репозитории: клонирование из списка аккаунта или по URL (HTTPS/SSH), создание с `.gitignore`, лицензией и README, публикация на GitHub/GitVerse, недавние репозитории, удаление.
- GitHub и GitVerse: несколько аккаунтов одновременно, запросы на слияние (создание, просмотр файлов, обсуждение, ревью, слияние), задачи (создание, комментарии, метки, закрытие), форки с настройкой `upstream`, уведомления (GitHub).
- Безопасность: токены в системной связке ключей (libsecret через Electron safeStorage), при её отсутствии — файл, зашифрованный AES-256-GCM ключом из пароля (scrypt); токены маскируются в журналах; только HTTPS.
- Интерфейс: русский (по умолчанию), английский, китайский (частично); тёмная/светлая/системная тема; масштаб 100–200 %; адаптация под 1280×800; настраиваемые горячие клавиши; встроенная справка.

## Установка

- Steam Deck / SteamOS и любой Linux без root: [docs/install-steamdeck.md](docs/install-steamdeck.md)
- Debian / Ubuntu / Mint / Pop!_OS: [docs/install-debian.md](docs/install-debian.md)

Готовые сборки — на странице [Releases](https://github.com/Serge-Nook/kot-kod/releases). Рядом лежит `SHA256SUMS.txt` для проверки.

Требуется Git версии 2.35 или новее.

## Разработка

См. [docs/developer.md](docs/developer.md).

```bash
npm ci
npm run dev          # запуск в режиме разработки
npm test             # юнит- и интеграционные тесты
npm run build:linux  # AppImage и .deb в dist/
```
