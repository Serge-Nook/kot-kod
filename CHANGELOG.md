# История изменений

## 0.1.0 — 2026-11-07

Первая версия.

- Локальные операции Git: статус, различия, индексация файлов/блоков/строк, коммит и amend, соавторы, история с графом и поиском, ветки, merge/squash/rebase, интерактивный rebase, конфликты, stash, cherry-pick, revert, reset, теги, remote, `.gitignore`.
- GitHub и GitVerse: несколько аккаунтов (персональный токен; вход через браузер для GitHub при указании OAuth Client ID), клонирование из списка, публикация, удаление, форки, запросы на слияние, задачи, уведомления (GitHub).
- Хранение токенов в libsecret или в зашифрованном паролем файле.
- Интерфейс на русском, английском и (частично) китайском; темы; масштаб 100–200 %; горячие клавиши; встроенная справка.
- Сборки AppImage и deb с контрольными суммами SHA-256.
