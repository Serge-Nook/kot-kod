# Установка на Steam Deck (SteamOS 3.x)

Root-доступ не нужен.

1. Переключитесь в **Desktop Mode** (Steam → Питание → Переключиться на рабочий стол).
2. Скачайте `Kot-kod-<версия>-x86_64.AppImage` со страницы [Releases](https://github.com/Serge-Nook/kot-kod/releases).
3. Проверьте контрольную сумму (необязательно):
   ```bash
   sha256sum -c SHA256SUMS.txt --ignore-missing
   ```
4. Сделайте файл исполняемым: правый щелчок → Свойства → Права → «Является исполняемым», или в терминале:
   ```bash
   chmod +x ~/Downloads/Kot-kod-*-x86_64.AppImage
   ```
5. Запустите двойным щелчком.

Git в SteamOS уже установлен. Проверить: `git --version` (нужна 2.35+).

## Запуск из Game Mode

1. В Desktop Mode откройте Steam → «Игры» → «Добавить стороннюю игру в Steam…» → «Обзор…» и выберите AppImage.
2. Вернитесь в Game Mode — «Кот-код» появится в библиотеке в разделе «Сторонние».
3. Экранная клавиатура: **Steam + X**. Масштаб интерфейса меняется в «Настройки → Масштаб интерфейса» или клавишами `Ctrl +` / `Ctrl −`.

В Game Mode системная связка ключей обычно недоступна, поэтому при первом запуске приложение попросит придумать пароль для шифрования токенов.

## Обновление

«Настройки → Проверить обновления» скачивает новую версию AppImage и заменяет текущую после перезапуска.

## Удаление

Удалите файл AppImage. Настройки и журналы лежат в `~/.config/kot-kod` и `~/.local/state/kot-kod`.
